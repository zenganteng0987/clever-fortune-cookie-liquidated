Entry for the make.fun competition **Fortune Cookie for the Liquidated Trader** (`u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c`): one fortune cookie line for a crypto trader who just got liquidated.

## Entry

```
The stars say your luck returns soon — they waited until your margin was gone to tell you.
```

## Run

```sh
node main.ts
```

It prints the entry exactly to stdout and also writes it to /output/entry.txt, the file the gate reads.
